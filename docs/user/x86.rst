x86 support
===========

Gluon can run on normal x86 systems, for example virtual machines
and VPN boxes. By default, there is no WLAN support on x86 though.

Targets
^^^^^^^

The following targets for x86 images exist:

`x86-64`
    Generic x86 64-bit support with many different ethernet drivers; should run on
    most x86 systems with 64-bit support.

    There are three images:

    * `generic` (compressed "raw" image, can be written to a disk directly or booted with qemu)
    * `virtualbox` (VDI image)
    * `vmware` (VMDK image)

    These images differ in the image file format, the content is the same. Therefore
    a single `x86-64` sysupgrade image is provided, only.

`x86-generic`
    32-bit version of `x86-64` for hardware not supporting 64-bit images.
    Also comes with `virtualbox` and `vmware` factory installs.

`x86-geode`
    x86 image for Geode CPUs.

`x86-legacy`
    x86 image for very old PC hardware like i586.


Network interfaces
^^^^^^^^^^^^^^^^^^

Unless a board defines its own interface names, the first Ethernet interface
is used for LAN and the second one for WAN. On upgrades, the interfaces keep
their roles as long as they still exist; if an interface is gone or the
number of interfaces of a role has changed, the defaults apply.

The names of Ethernet interfaces do not depend on the order in which their
drivers are loaded:

* PCI and virtio interfaces are named after their PCI address, as on other
  Linux distributions (e.g. `enp1s0`).
* USB Ethernet adapters are named after the second half of their MAC address
  (e.g. `usb534458` for `00:e0:4c:53:44:58`).

Adapters without a fixed MAC address, or with the same name as another
adapter, keep their name `ethX`.
